## Какво сме научили до тук

### Придобити знания:
- Бройни системи: двоична ↔ десетична.
- Променливи: имена, декларация, присвояване.
- Типове: int, double, bool, char, string.
- Аритметика: +, -, *, /, %, ++.
- Сравнения: ==, !=, <, >, <=, >=.
- Логика: &&, ||, !.
- Условия: if, if/else, вложени и последователни if, else if.
- Цикли: while, for.
- Алгоритмично мислене: проследяване на код, брояч, сума, промяна на стойности.
