## Домашна работа: Украса от думи
### Напишете конзолна програма, която прочита дума и положително цяло число N. Програмата трябва да повтори думата N пъти, като постави разделителя " - " само между повторенията.

Примерен вход:
```
echo
4
```
Очакван изход:
```
echo - echo - echo - echo
```
### Част 1. Решение със string
Започнете с празен низ. Използвайте цикъл for и оператора +=, за да добавяте думата и разделителя. Изведете целия резултат с едно извикване на Console.WriteLine() след цикъла.

### Част 2. Решение със StringBuilder
Преработете решението, като използвате StringBuilder и метода Append(). След цикъла извикайте ToString() и отпечатайте получения низ. Проверете дали двете версии извеждат еднакъв резултат.

Подсказка: Добавяйте разделителя преди всяко повторение след първото. 
Проверете програмата и с N = 1. Тогава резултатът трябва да е само: 
```
echo
```
