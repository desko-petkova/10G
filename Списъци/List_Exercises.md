# Упражнение: Работа с List<T> в C#

## Указания
Разработете конзолна програма за управление на резултати от състезание. Изпълнете задачите последователно в един Main() метод. Обозначавайте номера на всяка задача в изхода.

След всяка промяна извеждайте списъка:

```csharp
Console.WriteLine(string.Join(", ", scores));
```

Начален списък:

```csharp
List<int> scores = new List<int>
{
    45, 80, 60, 80, 25, 95, 40
};
```

## Важни уточнения

| Елемент | Предназначение |
|---|---|
| Count | Брой елементи — свойство |
| Capacity | Капацитет на вътрешното хранилище — свойство |
| scores[index] | Достъп до елемент чрез индекс |
| Remove(value) | Премахва първото срещане на стойността |
| RemoveAt(index) | Премахва елемента на посочения индекс |
| IndexOf(value) | Връща първия намерен индекс или -1 |
| Find(condition) | Връща първия съвпадащ елемент или default(T) |
| BinarySearch(value) | Търси в списък, сортиран със същия ред на сравнение |
| AsReadOnly() | Създава изглед, през който списъкът не може да се променя |

При List<int> Find() връща 0, ако няма съвпадение. Тъй като 0 може да е реален елемент, използвайте Exists() или FindIndex(), за да установите дали има съвпадение.

GetRange() създава отделен списък. В това упражнение елементите са int и промяната им в копието не променя оригинала. При референтни типове копирането на списъка не създава автоматично копия на самите обекти.

AsReadOnly() е изглед към оригиналния списък и отразява промените в него.

TrimExcess() може да намали Capacity; не променя Count или стойностите на елементите. Ако списъкът е почти запълнен, капацитетът може да остане същият.

## Критерии за проверка
- Всички задачи се изпълняват последователно в един Main().
- Междинните резултати са ясно обозначени.
- Индексите и диапазоните са валидни.
- Разграничава се премахване по стойност и по индекс.
- BinarySearch() се използва след сортиране.
- Ламбда изразите задават правилните условия.
