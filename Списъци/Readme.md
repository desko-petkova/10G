# Списъци в C#
## Списък List<T> е динамична структура от данни, подобна на масив,
 но може да променя размера си автоматично – добавя, премахва и вмъква елементи.
```csharp
	<T> означава тип на елементите – int, string, double, bool, char, object
```
Пример:
```csharp
	List<int> numbers = new List<int>();
```
## Основни характеристики
- Елементите са подредени и достъпни чрез индекс.
- Позволява динамично добавяне/премахване на елементи.
- Част е от пространството имена:  using System.Collections.Generic;

## Създаване на списък
```csharp
	List<int> nums = new List<int>();
	List<string> names = new List<string>() { "Ivan", "Maria" };
```
## Основни операции
➤ Добавяне
```csharp
	nums.Add(10);
```
➤ Достъп чрез индекс
```csharp
	int x = nums[0];
	nums[1] = 50;
```
➤ Размер на списъка
```csharp
	int count = nums.Count;
```
➤ Премахване
```csharp
	nums.Remove(10);       // премахва първото срещане на 10
	nums.RemoveAt(2);      // премахва елемент на позиция 2
	nums.Clear();          // изчиства списъка
```
➤ Търсене
```csharp
	bool found = nums.Contains(5);
	int index = nums.IndexOf(5);    // -1 ако липсва
```
## Обхождане на списък
➤ чрез for оператор:
```csharp
	for (int i = 0; i < nums.Count; i++)
    		Console.WriteLine(nums[i]);
```
➤ чрез foreach:
```csharp
	foreach (int n in nums)
    		Console.WriteLine(n);
```
## Вмъкване на елемент
```csharp
	nums.Insert(1, 99);   // на индекс 1 вмъква 99
```
## Полезни методи
Метод		Описание
Add()		Добавя елемент
AddRange()	Добавя няколко елемента
Insert()	Вмъква на определен индекс
Remove()	Премахва по стойност
RemoveAt()	Премахва по индекс
Contains()	Проверява дали съществува елемент
IndexOf()	Връща индекса на елемент
Sort()		Подрежда елементите
Reverse()	Обръща реда

## Алгоритми за сортиране на елементи на списък

1. Метод на мехурчето (Bubble Sort)

Обща информация: Bubble Sort е един от най-простите алгоритми за сортиране.
		 Името идва от идеята, че както мехурчета се издигат нагоре във вода, 
		 така и големите елементи постепенно „изплуват“ към края на списъка.

Алгоритъмът:
	1. Обхожда списъка чрез вложени два цикъла:
		външен цикъл – контролира колко пъти ще се обходи списъкът
		вътрешен цикъл – прави една обиколка, в която сравнява съседни елементи
	Това гарантира, че списъкът ще бъде обработен многократно, докато стане напълно подреден.
	2. На всяка итерация сравнява два съседни елемента.
	3. Ако са в грешен ред → разменя ги.
	4. След всяка пълна обиколка най-големият елемент „изплува“ в края.
	5. Повтаря, докато целият списък стане подреден.
